# Bolt's Journal

## 2024-05-22 - [Static Site Image Optimization]
**Learning:** In a pure static HTML/CSS codebase without a build process, the most significant performance wins come from optimizing assets (images, CSS) and ensuring efficient loading strategies (lazy loading) rather than code execution paths.
**Action:** Prioritize `loading="lazy"` on images and resource hints like `rel="preload"` or `preconnect`.
